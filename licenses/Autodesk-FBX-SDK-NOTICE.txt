Autodesk FBX SDK notice

Universal Scene Converter's FBX support is built with Autodesk FBX SDK 2020.3.9.
The Autodesk FBX SDK installer is used only during compilation and is not redistributed in the Universal Scene Converter package.
The resulting Universal Scene Converter binary contains Autodesk FBX code linked into Adobe's USD FBX file-format plugin.
